# Модуль terminal

Терминал, запуск файлов и окружение Linux.

## Как это работает
- Окружение: Alpine Linux (minirootfs) в `files/linux/rootfs`. Архив скачивается с dl-cdn.alpinelinux.org, сверяется по SHA-256 из `latest-releases.yaml` и распаковывается системным `tar`. Потом ставится `util-linux-misc` (даёт `script`). Без него установка считается неудавшейся.
- Запуск: `libproot.so` из папки нативных библиотек приложения, загрузчик через `PROOT_LOADER` на `libproot-loader.so`. Так обходится запрет запуска файлов из `files/` на Android 10+.
- Рабочая папка проекта подключена в окружении как `/workspace`.
- pty: оболочка запускается через `script`, поэтому работают Ctrl+C, редакторы и менеджеры процессов.
- Размер: приложение измеряет панель в символах, пишет размер в `/tmp/aircode-size` внутри окружения, а скрипт `aircode-inner` раз в секунду применяет его через `stty`. Запущенная программа получает SIGWINCH.
- Эмулятор `TerminalBuffer`: SGR (16, 256 и 24-битные цвета), курсор, очистка, вставка и удаление строк и символов, области прокрутки, альтернативный экран, сохранение курсора, DEC-рамки, широкие символы и эмодзи, ответы на запросы курсора и устройства, режим стрелок для vim.
- Клавиши: Ctrl и Alt (залипающие), стрелки, Home, End, PgUp, PgDn, Del, Ins, F1-F12, Esc, Tab. «Прямой ввод» отправляет каждое нажатие сразу и включается сам в полноэкранных программах. Физическая клавиатура поддерживается.
- Служба переднего плана `TerminalService` держит процесс, пока есть сессии или идёт установка, и не даёт процессору заснуть. В уведомлении есть кнопка «Остановить». На Android 13+ приложение просит разрешение на уведомления.
- Запуск файла открывает вкладку «Запуск: имя», сам доустанавливает нужные пакеты и показывает код завершения.

## Языки запуска
| Расширение | Команда | Пакеты |
|---|---|---|
| py | `python3` | python3 |
| js, mjs, cjs | `node` | nodejs |
| java | `java Файл.java` | openjdk21-jdk |
| c | `gcc`, затем запуск | build-base |
| cpp, cc, cxx | `g++`, затем запуск | build-base |
| cs | `mcs`, затем `mono` | mono |
| m, mm | `gcc -x objective-c` | build-base, gcc-objc |

Свои языки, в том числе Cream, подключаются файлом `aircode-runners.txt` в корне рабочей папки:

```
cream = cream {file}
cream.packages = git
rb = ruby {file}
rb.packages = ruby
```

В команде работают `{file}`, `{dir}`, `{name}`, пути подставляются уже в кавычках. Запись для уже встроенного расширения заменяет встроенную команду.

## Бинарники proot
Шаг CI `scripts/fetch-proot.sh` клонирует [green-green-avk/build-proot-android](https://github.com/green-green-avk/build-proot-android) (proot со встроенным libtalloc и отдельным загрузчиком), находит для каждой архитектуры `proot` и `loader` и кладёт их в `terminal/src/main/jniLibs/<abi>/` как `libproot.so` и `libproot-loader.so`. Скрипт ищет файлы по структуре репозитория, не опираясь на точные имена архивов. Если ничего не нашёл, он печатает содержимое репозитория, а APK собирается без proot (работает только оболочка Android).

Локально: `bash scripts/fetch-proot.sh`, строгий режим `PROOT_REQUIRED=1`. Свои бинарники можно положить в `jniLibs` вручную.

`app/build.gradle.kts` включает `useLegacyPackaging`, чтобы библиотеки распаковывались в папку приложения.

## Что проверить на устройстве
1. Без бинарников: терминал открывается, баннер сообщает про оболочку Android, `ls` работает.
2. С бинарниками: баннер «Установить Linux», загрузка идёт с процентами, после установки приглашение `root@aircode`.
3. `apk add vim htop`, затем `vim` и `htop`: экран рисуется, стрелки и Esc работают, при развороте панели размер подстраивается.
4. Меню ⋮ → «Запустить файл» на `main.py`, `Main.java`, `a.c`, `Program.cs`.
5. Ctrl+C останавливает `sleep 30`. Свернуть приложение на несколько минут, сессия жива.
6. Терминал открывается с экрана файлов (меню ⋮).

## Известные особенности
- Android 12+ убивает приложения, у которых больше 32 дочерних процессов. Если это мешает, отключите ограничение командой `adb shell device_config put activity_manager max_phantom_processes 2147483647`.
- Мышь в терминале (режимы xterm 1000 и выше) не передаётся, прокрутка колесом в программах не работает.
- Курсор в строке с широкими символами может отображаться со сдвигом.
- Запуск C# идёт через mono (`mcs`), поэтому современные возможности .NET недоступны. Для них задайте свою команду в `aircode-runners.txt`.
