# Веб-часть редактора

Исходники CodeMirror 6 для WebView. Готовый бандл лежит в
`../src/main/assets/editor/editor.bundle.js` и хранится в репозитории,
поэтому для обычной сборки APK Node.js не нужен.

Пересборка бандла после правок в `src/main.js` или смены зависимостей:

```
npm ci
npm run build
```

Лицензии зависимостей (CodeMirror, MIT) нужно включить в список лицензий к релизу v1.0.
