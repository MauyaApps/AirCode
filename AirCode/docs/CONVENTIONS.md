# AirCode — правила кода

## Язык и стиль
- Kotlin, официальный code style. Compose-функции в PascalCase.
- В коде нет комментариев вообще, включая KDoc (требование автора). Документация в md-файлах на русском. Имена в коде на английском.
- Без неиспользуемого кода и мёртвых заглушек.

## Структура
- Один модуль — одна ответственность. Зависимости идут только вниз (`app` → остальные).
- UI-состояние в ViewModel, UI не лезет в файловую систему напрямую.
- Общие константы и строки — в ресурсах, не в коде.

## Безопасность
- API-ключи только в Keystore. Не логировать ключи, токены и содержимое файлов пользователя.
- Запросы к провайдеру AI уходят только к выбранному пользователем провайдеру.

## Совместимость
- minSdk 24 в v1.0. Новые API Android — только с проверкой версии и запасным вариантом.
- Эффекты вроде blur и «жидкого стекла» только на Android 12+ с запасной темой.

## Git и сборка
- Небольшие коммиты, понятные сообщения на русском.
- Релизные APK подписываются; ключ подписи не хранится в репозитории.

## Тесты
- Модульные тесты для ядра (файловая система, мост, парсинг).
- Проверка основных сценариев вручную перед релизом.
