# AirCode — дорожная карта

## v0.1 — Редактор (MVP)
Редактор, дерево файлов, вкладки, подсветка (включая Cream), поиск, командная палитра, автодополнение по разрешению, Markdown/HTML-просмотр, панель символов, три темы, экран краша.

Статус: весь список написан, ждёт проверки на устройстве. Перемещение файлов и импорт/экспорт через SAF вынесены на после MVP.

## v0.2 — Темы (сборки 0.2test)
Настройки темы: режим (светлая, тёмная, системная) и стиль — базовая, Material You (из обоев на Android 12+ или из своих цветов: основной, дополнительный, акцентный, фон; у каждого свой контраст), свой цвет (готовые цвета, оттенок, #RRGGBB), «жидкое стекло» (Android 12+, на старых версиях заменяется базовой). Черновики папок и файлов в памяти с сохранением в рабочую папку. Доводка v0.1 по результатам проверки на телефоне.

## v0.3 — Терминал и запуск (сборки 0.3test)
proot-окружение, терминал, вкладки терминала, запуск Python/Java/JS/C-семейства, нижняя панель вывода, установка пакетов. Начать с прототипа: запустить оболочку в proot на устройстве.

Статус 0.3test5: во встроенном редакторе номера строк, красная подсветка ошибок (скобки, незакрытые строки и комментарии, опечатки в ключевых словах, пропущенные «:» в Python и «;» в Java, C, C++, C#, Objective-C) и меню исправлений по нажатию на красный текст.

Статус 0.3test4: добавлен встроенный редактор на Compose (по умолчанию, без WebView, с подсветкой Cream, Python, Java, JavaScript, C/C++, C#, Objective-C). CodeMirror в WebView остаётся как режим, переключение командой в палитре.

Статус 0.3test3: исправление пустого редактора. Убраны скрытия экранов через прозрачность (WebView переставал рисоваться), по умолчанию включена программная отрисовка WebView, при показе редактора выполняется перерисовка. В палитре команд есть переключение режима отрисовки, «Редактор: перерисовать» и «Редактор: диагностика».

Статус 0.3test2: модуль `terminal` с полным эмулятором (полноэкранные программы vim, nano, htop, less, mc), размером терминала по экрану, клавишами Ctrl, Alt, стрелками, F1-F12 и прямым вводом. Alpine Linux ставится при первом запуске, оболочка работает через proot. Запуск файлов: Python, JavaScript, Java, C, C++, C# (mono), Objective-C и любые другие по файлу `aircode-runners.txt` в рабочей папке. Служба переднего плана держит сессии и установку в фоне. Терминал открывается из редактора и с экрана файлов. Бинарники proot подтягивает шаг CI `scripts/fetch-proot.sh`. Подробности: `terminal/README.md`. Нужна проверка на устройстве.
