# AirCode — дорожная карта

## v0.1 — Редактор (MVP)
Редактор, дерево файлов, вкладки, подсветка (включая Cream), поиск, командная палитра, автодополнение по разрешению, Markdown/HTML-просмотр, панель символов, три темы, экран краша.

Статус: весь список написан, ждёт проверки на устройстве. Перемещение файлов и импорт/экспорт через SAF вынесены на после MVP.

## v0.2 — Терминал и запуск
proot-окружение, терминал, вкладки терминала, запуск Python/Java/JS/C-семейства, нижняя панель вывода, установка пакетов.

## v0.3 — AI
Gemini, OpenRouter, Claude. Чат через бургер-меню, переключение «редактор / AI». Агент с подтверждением правок и режимом «без подтверждения». Наработки из CodeAI.

## v0.4 — LSP и отладчик
Языковые серверы в proot, диагностика, переход к определению, отладка с точками останова.

## v0.5 — Плагины
JS + WASM, манифест, права, Open VSX, грамматики TextMate. Cream получает подсветку по своей грамматике (во встроенном виде она есть уже в v0.1).

## v0.6 — Темы и устройства
Редактор тем, планшеты, внешняя клавиатура, горячие клавиши.

## v1.0 — Публичный релиз
Сайт, F-Droid, GitHub-релиз, политика конфиденциальности, лицензии зависимостей.

## После v1.0
Подписка, iOS, Git, облачная синхронизация, свой каталог расширений, понижение minSdk до 21.
