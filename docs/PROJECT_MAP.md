# AirCode — карта проекта

## Суть
AirCode — VS Code-подобный редактор кода для Android. Для всех кодеров: от новичков до опытных. Публичный релиз, бесплатный (подписка возможна позже).

- Автор: Влад (Mauya Apps), работает в режиме vibe-coding: ИИ пишет код, автор переносит и собирает.
- Распространение: F-Droid, GitHub (релизы), отдельный сайт.
- Язык документации и комментариев: русский (на старте).

## Принятые решения
| Область | Решение |
|---|---|
| Платформа | Android. В v1.0 minSdk 24 (Android 7.0). iOS позже |
| Язык и UI | Kotlin + Jetpack Compose, Material 3 |
| Темы | светлая, тёмная, системная (с самого начала) |
| Движок редактора | CodeMirror 6 в WebView (предложено, подтвердить) |
| Офлайн | полностью офлайн; скачивание пакетов и библиотек требует интернета |
| Языки (подсветка и запуск) | Python, Java, JavaScript, C-семейство (C, C++, C#, Objective-C), Cream |
| Терминал | proot-окружение как в Termux + встроенные интерпретаторы по ситуации |
| AI | Gemini, OpenRouter, Claude. Правки файлов с подтверждением, режим «без подтверждения» включается пользователем |
| Расширения | полноценные плагины (JS + WASM). Из VS Code берём только грамматики. Каталог: Open VSX, позже свой |
| Ошибки | экран краша с отправкой отчёта на почту автора (без сервера) |
| Проекты | хранятся локально внутри приложения |
| Монетизация | сначала бесплатно, подписка позже |

## MVP (v0.1)
1. Редактор и просмотр файлов.
2. Дерево файлов, вкладки, открытие, правка, сохранение.
3. Подсветка синтаксиса: Python, Java, JS, C-семейство, Cream.
4. Поиск по файлу (как Ctrl+F).
5. Командная палитра.
6. Автодополнение — включается только с разрешения пользователя.
7. Просмотр Markdown и HTML.
8. Панель символов над клавиатурой (`{ } ( ) [ ] ; : Tab`).
9. Светлая, тёмная, системная темы.
10. Экран краша с отправкой на почту.

## Не входит в MVP
AI, редактор тем, расширения, Git, облачная синхронизация, планшеты и внешняя клавиатура, терминал, отладчик.

## Открытые вопросы
- Понижение minSdk: Compose работает от Android 5.0 (API 21), поэтому «4+» невозможно; в новых версиях цель — API 21.
- Сборка APK на телефоне: цель, но не блокер; запасной путь — GitHub Actions.
- Лицензия проекта (для F-Droid нужна открытая).
- Движок редактора CodeMirror 6 используется, решение подтверждено.
- Подсветка Cream сделана встроенной (по грамматике из репозитория cream-lang), в v0.5 заменяется плагином.
- Лицензии зависимостей (CodeMirror, commonmark — MIT/BSD) включить в список к релизу v1.0.
- Референс по виду: VS Code. Жесты курсора и выделения уточнить позже.
